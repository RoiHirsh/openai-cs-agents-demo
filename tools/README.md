# tools/

Reference data and review artifacts from the current bot iteration. Kept for use in future iterations.

| File | Description |
|------|-------------|
| `corrections_actioned.json` | Historical log of corrections that were reviewed and actioned |
| `faq_approved.json` | Approved FAQ Q&A pairs snapshot |
| `handoff_approved.json` | Approved handoff trigger scenarios snapshot |
| `qa_master.json` | Master Q&A dataset used for knowledge base seeding |
| `remaining_data.js` | Legacy data export (JS format) from an earlier import pipeline |
| `remaining_review.json` | Historical review queue snapshot |
| `corrections-review.html` | Standalone review UI for corrections (superseded by dashboard) |
| `faq-review.html` | Standalone review UI for FAQ entries (superseded by dashboard) |
| `handoff-review.html` | Standalone review UI for handoff triggers (superseded by dashboard) |
| `remaining-review.html` | Standalone review UI for remaining data (superseded by dashboard) |
| `fetch_feedback.py` | One-off script to fetch and export feedback data from Supabase |
| `side-by-side.md` | Side-by-side comparison notes from a review session |
